# Shapiro-Wilk normality test (coefficients)

Coefficients (a_(i)) for the W test for normality.

## Usage

``` r
Shapiro_Wilk_coef_table
```

## Format

A data frame with 50 rows and 25 variables:

rownames is the sample size (n); colnames is the corresponding
coefficients (ahtml_(ihtml)).

## References

Shapiro, S.S., Wilk, M.B., 1965. An Analysis of Variance Test for
Normality (Complete Samples). Biometrika 52, 591–611.
https://doi.org/10.2307/2333709
