# Shapiro-Wilk normality test (p-values)

The percentage points (critical values of W) of the W test for n =
3(1)50.

## Usage

``` r
Shapiro_Wilk_pval_table
```

A data frame with 50 rows and 10 variables:

Shapiro, S.S., Wilk, M.B., 1965. An Analysis of Variance Test for
Normality (Complete Samples). Biometrika 52, 591–611.
